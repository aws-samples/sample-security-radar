# Security

## Reporting a vulnerability

If you discover a potential security issue in this project, we ask that you notify AWS/Amazon Security via our
[vulnerability reporting page](http://aws.amazon.com/security/vulnerability-reporting/) or directly via email to
[aws-security@amazon.com](mailto:aws-security@amazon.com). Please do **not** create a public GitHub issue.

## Scope notes

- `integrations/continuum/targets/` contains **deliberately vulnerable demo targets** (scan targets for the demo).
  Their findings are intended; do not deploy them and do not reuse any key in them.
- This is sample code for a **non-production** account. See the Disclaimer in the README.
