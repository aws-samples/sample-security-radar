# Contributing

This project follows the touchstone workflow: **criteria before code, every guard proven able to fail.**

## Before you push

```bash
uv sync
uv run ruff check src tests infra scripts
uv run pytest -q -n auto
uv run python ~/.claude/skills/touchstone/tools/mutate.py --cmd "uv run pytest -q -x -n auto -p no:cacheprovider" mutations.txt   # every mutation in mutations.txt must turn its test red
(cd ui && npm ci && npm test && npm run build && npm run a11y)
```

CI on GitLab runs the same gates (see `.gitlab-ci.yml`). GitHub Actions only run on `v*` tags or manually.

## Rules that are enforced

| Rule | Where it is enforced |
|---|---|
| A new guard needs a test **and** a mutation entry that turns it red | `mutations.txt`, CI `mutation` job |
| LLM output never decides severity, level, ranking or numbers | `src/radar/analyst.py` validation, `tests/test_analyst.py` |
| UI types are generated from `schemas/site-data.schema.json`, never hand-edited | CI `schema-types` |
| three.js only in the lazy `#/wall` chunk, ≤150 KB gzip | `ui/scripts/check-chunks.mjs` (part of `npm run build`) |
| Text contrast WCAG AA in both themes | `npm run a11y` (axe) |
| Degradation is visible, never silent ("no data" ≠ "ok") | tests in `tests/test_collect.py`, `ui/src/test/` |
| Secrets only from `~/.env` / Secrets Manager; never in code, argv or logs | review + `git grep` in CI hygiene |

## Docs

- Current design: `docs/DESIGN.md`, plans `docs/design/*.md`. Research (archive, not required reading): `docs/research/`.
- Diagrams are generated by arcflow from `docs/diagrams/*.json` — edit the JSON, re-render, never hand-edit SVG.
- `CHANGELOG.md`: every entry has a measured number or a reproduction path.
